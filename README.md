# 装備コンパス — MHWilds スキル装備シミュレーター

護石のスキルと「付けたいスキル」を選ぶだけで、それを満たす防具の組み合わせ（装飾品含む）を探す、静的なWebアプリ（HTML/CSS/JSのみ、ビルド不要）です。スマホのブラウザにも対応しています。

## ファイル構成

```
index.html          markup のみ
css/style.css        デザイン（配色・タイポグラフィ・モバイル対応）
js/api.js            wilds.mhdb.io からのデータ取得（CORS対策のフォールバック込み）
js/matching.js        データ整形・防具のスコアリング・装飾品の割り当てロジック
js/render.js          スキル選択UI・結果表示のDOM描画
js/main.js            状態管理・画面の初期化・検索の実行
```

ビルド不要なので、`index.html` をそのままブラウザで開く／GitHub Pagesに置くだけで動きます。

## しくみ

- 防具・スキル・装飾品・護石・防具シリーズ（グループスキル判定用）のデータは、非公式APIの [wilds.mhdb.io](https://wilds.mhdb.io)（日本語ロケール）から**ブラウザが直接**取得します。データはリポジトリに含まれていないので、ゲームアップデートで内容が変わっても、コードを直接書き換えずに追従できます。
  - APIへの直接アクセスがブロックされる環境（CORS制限など）では、自動的に公開CORSリレー（`api.allorigins.win`）経由での取得にフォールバックします。
- **護石スキルの選択**は、実際に護石に付き得るスキルだけに絞り込んであります（`/charms` の実データから、実際に護石ランクに登場するスキルIDだけを抽出）。加えて、レア8の鑑定護石（栄世の護石）は武器スキルも複合して持てるため、武器スキルも選択できるようにしています（「武器スキル（レア8護石のみ）」として区別表示）。
- **付けたいスキルの選択**は、通常の防具スキルに加えて「グループスキル」（異なるシリーズ間でも規定部位数を集めると発動するボーナス）も選べます。実際に何らかの防具シリーズが付与するグループスキルのみを候補にしています。
- マッチングは「スキルで絞り込んで候補を提示する」簡易検索です。各部位（頭/胴/腕/腰/脚）ごとに、目標スキル（＋目標グループスキルに関連するシリーズ）への貢献度が高い防具を上位12件スコアリングし、既定では最上位を自動選択、プルダウンで他の候補にも切り替えられます。
- 装飾品は、選んだ防具のスロットが余っている分に対して、不足しているスキルを埋めるように簡易的な貪欲法（グリーディ法）で自動的に割り当てます。
- グループスキルの達成度は、実際に選ばれている5部位のうち、同じグループスキルを持つシリーズの防具が何個あるかを数えて判定します（プルダウンで防具を変更すると自動的に再計算されます）。
- 武器そのもののスキル／セットボーナス（同一シリーズのボーナス）／護石のランダム生成テーブルは考慮していません（意図的にスコープ外にしています）。

## GitHubへの公開方法（GitHub Pages）

1. このフォルダの中身（`index.html`, `css/`, `js/`, `README.md`）をリポジトリのルート（またはお好きなフォルダ）にコミット＆プッシュします。ファイル構成・相対パスは変えないでください。
2. GitHubリポジトリの **Settings → Pages** を開きます。
3. **Source** を `Deploy from a branch` にし、ブランチを `main`（または該当ブランチ）、フォルダを `/ (root)` に設定して **Save**。
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアプリにアクセスできます（スマホからもそのままアクセス可能です）。

## カスタマイズのヒント

- `js/matching.js` の `PARTS` 配列で部位のラベルなどを調整できます。
- スコアリングは `scoreArmor()`、装飾品の割り当ては `assignDecorations()`、グループスキルの達成判定は `computeGroupAchieved()` にまとまっています。セットボーナス（同一シリーズ限定のボーナス）を組み込みたい場合も、この付近を拡張するのが起点になります。
- 配色・フォントなどのデザイントークンは `css/style.css` の `:root` 変数にまとめてあります。

## 注意事項

- 本ツールはファンメイドの非公式ツールで、CAPCOM・Monster Hunter Wilds公式とは関係ありません。
- データ提供元 [wilds.mhdb.io](https://wilds.mhdb.io) はコミュニティによる非公式APIのため、仕様変更や一時停止の可能性があります。
- 護石の「武器スキル」は、実際のレア8鑑定護石の抽選テーブル（組み合わせ・出現率）までは再現していません。あくまで「選べる」だけの簡易表現です。
